# Salariometro

Salariometro contextualiza un salario con datos oficiales de Espana y explica con claridad la fuente, el periodo, la poblacion comparada y las limitaciones de cada resultado.

El proyecto esta en su fase inicial. Su primer componente es una skill de calidad de datos para que las fuentes, los calculos y los textos del producto sean trazables y estadisticamente defendibles.
